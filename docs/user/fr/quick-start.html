Démarrage rapide Kids Galaxy

Gardez cette page à côté du projecteur.

Les étapes complètes sont dans le guide d’installation et le guide de tous les jours.

Avant l’arrivée des enfants

Environ 5 minutes.

  • L’ordinateur est allumé et montre le bureau.
  • Le projecteur est allumé et montre cet ordinateur.
  • Les deux tablettes sont sur le même Wi-Fi que l’ordinateur.
  • Le mur montre le ciel sombre.

Allumer la salle

  • Allumez l’ordinateur. Attendez le bureau.
  • Allumez le projecteur. Choisissez HDMI.
  • Sur l’ordinateur, ouvrez `http ://127.0.0.1:8000/`.
  • Appuyez sur F11 pour remplir l’écran.
  • Réveillez les tablettes.

Un enfant dessine

  • Sur la tablette enfant, touchez une forme et dessinez.
  • Touchez Lancer.
  • Regardez le mur. La nouvelle planète devrait apparaître.

Un adulte

  • Ouvrez Gestionnaire Kids Galaxy. Ce n’est pas l’application de dessin.
  • Touchez EN / FR pour changer cette tablette.
  • Touchez Langue du projecteur pour changer les mots du mur.
  • Touchez Imprimer pour le papier. Touchez STL pour un fichier 3D.

Éteindre la salle

  • Éteignez l’ordinateur depuis le menu d’alimentation.
  • Éteignez le projecteur.
  • Laissez les tablettes dormir.

Si le mur est sombre

  • Vérifiez les deux voyants d’alimentation.
  • Vérifiez le câble HDMI et la source HDMI.
  • Sur l’ordinateur, ouvrez `http ://127.0.0.1:8000/`.
