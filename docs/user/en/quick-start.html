Kids Galaxy day card

Keep this page at the daycare. The daily guide has the full steps.

Arrive

  • Plug in the travel router. You should see a steady Wi-Fi light.
  • On the PC, join `KidsGalaxy`. Do not join the daycare Wi-Fi. You should see that name.
  • Turn on the PC and sign in to Windows. You should see the desktop.

Set up

  • Quit Docker Desktop if you see the whale icon. You should see the icon gone.
  • Open the Ubuntu app. You should see the name `omega`.
  • Paste `cd /home/omega/kids-galaxy-projector`. You should see no error.
  • Turn on the projector and choose HDMI. You should see the PC on the wall.
  • Paste `bash scripts/open_projector.sh`. You should see the dark sky.

Test

  • Wake the kid tablet. You should see the drawing app on `KidsGalaxy`.
  • Draw a small mark and tap Launch. You should see the mark on the tablet.
  • Look at the wall. You should see the new planet.

Pack up

  • On the manager tablet, tap Before you leave. You should see the planet names cleared.
  • Shut down Windows from the power menu. You should see the PC turn off.
  • Turn off the projector and unplug the router. Pack the router, the paper card, both tablets, and the chargers. You should see those items in the case.

If you are stuck

  • If the router light is off, check the power plug. You should see the Wi-Fi light.
  • If setup stops because Docker Desktop is running, quit it and run the line again. You should see the installed message.
  • If setup stops because the PC is not at `192.168.0.52`, join `KidsGalaxy`. Do not change the tablet address. You should see `192.168.0.52`.
  • If the tablet cannot find the room, join `KidsGalaxy` on the tablet too. You should see the same Wi-Fi name as the PC.

First time on a new tablet or after an update

These checks are not done yet. Nobody has run them on the real PC or tablet. Leave each box empty until you see the result yourself.

  • [ ] The child lock holds. A child cannot leave the drawing app. You should see Home stay in the app.
  • [ ] Restart the tablet. You should see the drawing app open by itself.
  • [ ] The tablet connects to the secure address on port `8443`. You should see no certificate warning. The address is `https://192.168.0.52:8443`.
  • [ ] In Windows PowerShell, run the setup script, the update script, and the stop script. You should see no red errors. Those scripts are `setup_room.sh`, `update_room.sh`, and `stop_room.sh`.
  • [ ] After an update, or a stop and a start, send one planet. You should see it on the wall within about 15 seconds. If not, reload the wall page. An automatic reconnect is not here yet. That fix is coming separately.
